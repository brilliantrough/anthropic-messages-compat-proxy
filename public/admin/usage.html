仅保存上游实际报告的数字，缺失值保留为未知。总输入 = input_tokens + cache_creation_input_tokens + cache_read_input_tokens；三项原始字段分别展示，任一缺失时总输入记为 NULL。缓存命中率 = 同时报告缓存读取与总输入的调用中，缓存读取量 / 总输入量（按 token 数加权）；Usage 覆盖率单独统计完整用量字段的已结束调用占比。图例最多展示 8 个主要系列，其余归为「其他」。时间分桶使用所选固定 UTC 偏移，不随夏令时变化。
